# DESIGN.md · 视觉、交互与文案设计

`ARCHITECTURE.md` 说明技术架构，本页规定视觉表现、交互依据和文案规则。修改界面前需阅读本页，完成后按第 9 节检查。

依据是 Apple HIG 和 iOS 26.2 的 Liquid Glass 三条原则：内容优先、形状随硬件、一套系统。

设计、交互和 SwiftUI 写法以 **iOS 26.2** 为基线；CI 用 Xcode 26.3 + `iPhoneSimulator26.2.sdk` 构建。最低运行版本仍是 iOS 17.0：26 及以上走 Liquid Glass，17–25 通过 `#available(iOS 26.0, *)` 回落到系统材质，两档共用本页的层级、间距与触控规则。

## 1. 颜色

只使用语义色。系统强调色 `Color.accentColor` 是例外。

| 用途 | token |
|---|---|
| 内容页底（正文、阅读） | `.systemBackground`，浅色白，深色黑 |
| 表单页底（设置、编辑器） | `.systemGroupedBackground`，对应 `Theme.groupedPageColor` |
| 表单卡片 | `.secondarySystemGroupedBackground`，对应 `Theme.groupedCard` |
| 内容页卡片 | `.secondarySystemBackground` |
| 输入框、标签 | `.tertiarySystemFill` |
| 选中态 | `.quaternarySystemFill` 加系统 tint 前景 |
| 文字 | `.primary`、`.secondary`、`.tertiary` |
| 分隔线 | `.separator` |

判断标准是去掉颜色后层级还成立不成立。不成立，说明在用颜色支撑层级，重做。

禁止使用高饱和品牌色作为全局 tint，禁止装饰性渐变和光晕。层次用系统材质、描边、轻投影、字号与留白来做，不靠颜色堆叠。

### 1.1 底色分工

白底和黑底只给内容：写作台、阅读页、正文编辑器。设置、世界资料、语料、提示词、导入导出这类表单页用系统分组底加白卡片，和 iOS 设置保持同一套关系。之前“灰卡片铺白底”在浅色下分不出边界，已经停用。

### 1.2 书封占位色

书架书脊可以用固定的 6 种低饱和纸色（`ShelfCoverPalette`）。色相固定、饱和度压低，按书项目 id 稳定取色，浅色和深色各一档。它是内容身份，不是品牌色，不用于按钮、开关、状态或页面底。这是“只用语义色”的唯一例外。真实封面优先，占位色只在没有封面时出现。

### 1.3 材质

Apple HIG 的规则是内容层不用 Liquid Glass。玻璃只属于导航和控件层：标签栏、工具栏、浮起的输入条、浮层。

| 层 | 用什么 |
|---|---|
| 导航和工具 | 系统默认，必要时 `.glassEffect` |
| 浮起的输入条 | `.glassEffect(.regular)` |
| 内容：气泡、卡片、正文 | 普通表面 + 细描边 + 轻投影；不用玻璃，也不用装饰性渐变 |

多个玻璃元素相邻时需置于 `GlassEffectContainer` 中，单个无需。内容层不加玻璃。`glassEffect` 只在 iOS 26 及以上生效，低版本由 `glassSurface(radius:)` 修饰符回落 `.regularMaterial`，不手绘玻璃背景。

### 1.4 层次与投影

| token | 用途 |
|---|---|
| `Theme.cardShadow` | 卡片轻投影，浅色 7% 黑、深色几乎不可见 |
| `Theme.cardSurface(radius:)` | 内容卡片：同色底、0.5pt 描边、8pt 投影，不叠玻璃 |

```text
层级顺序：页面底 → 卡片 → 内容
同屏最多一层卡片投影；不要把卡片放进卡片，也不要给正文加投影。
```

## 2. 字体

全部使用 `Font.TextStyle`，跟随 Dynamic Type，最小 `.caption`（12pt）。

例外：作品正文和码字机气泡用外观设置里的字号基数（默认 18pt，13–28 可调），这是产品需求；实际尺寸经 `UIFontMetrics` 跟随 Dynamic Type，见 `Core/Design/DynamicTypeFont.swift`。流式气泡、正文编辑器、阅读页和设置预览共用同一套换算。

| 用途 | token |
|---|---|
| 作品正文 | `.body`，系统字体（SF、PingFang），默认 18pt，可在外观里调 13 到 28 |
| 阅读大正文 | `.title3`，系统字体 |
| 区块标题 | `.headline` |
| 说明文字 | 已删除，不再写解释性小字 |
| 元信息 | `.caption` |
| 数字 | `.system(.footnote, design: .monospaced)` |

中英文都用 iOS 系统字体，不引入 `.serif`，不用自定义字体。默认正文 18pt。层级靠字号、字重和间距，不靠字体设计。

SwiftUI 的 `Text` 只有 leading、center、trailing，没有 justified。要两端对齐只能包 UIKit，设 `NSParagraphStyle.alignment = .justified`，不在当前范围。

## 3. 间距与圆角

```
间距  4 · 8 · 12 · 16 · 24 · 32
圆角  8 · 12 · 16 · 24      卡片 16，弹层 24
```

不使用 5、7、10、14。这些值属于非规范间距。

## 4. 动效

只用系统预设：`.snappy`、`.smooth`、`.bouncy`。必须有理由，比如选中、可发送、生成中。不做装饰性动画。

## 5. 布局

标签和值两端对齐，不靠空格凑：

```swift
HStack {
    Text(title).foregroundStyle(.secondary)
    Spacer(minLength: Theme.Spacing.s)
    Text(value).monospacedDigit()
}
```

按钮分三层：主操作用 `.borderedProminent`，一屏最多一个，次操作用 `.bordered`，行内动作用 `.secondary` 纯文字。

状态行只占一行，图标在文字前，动作在行尾。图标不得单独置于状态文字下一行。

键盘不用自定义「完成」工具条。滚动用 `.scrollDismissesKeyboard(.interactively)`，底部输入条放在 `.safeAreaInset(edge: .bottom)`，由系统处理键盘避让。

不得写死 `.frame(width:height:)`，Dynamic Type 放大会裁字。可点目标例外：图标按钮的视觉尺寸可以小，但热区必须至少 44×44pt，用 `.frame(minWidth:44,minHeight:44)` 或 `.contentShape(Rectangle())` 扩，不得只放大图标。

异步排版/打开的页面先显示加载态，不要先闪「内容为空」的空态；只有确认结果为空才出空态。

文件面板之后的确认不要用同层 alert：面板收起和弹层抢转场时后者会被静默丢掉。确认改为 `navigationDestination` 推入的页面，或等面板完全收起后再弹。

各级界面的要求：

| 级别 | 例子 | 要求 |
|---|---|---|
| 一级 | 5 个 Tab | 一屏做一件事，不嵌套工具栏 |
| 二级 | 设置分类页、世界页分段、阅读页 | 区块标题 `.footnote.weight(.semibold)`，一页不超过 4 个区块，一屏一个主操作 |
| 三级 | 人物卡、事件卡、世界书、语料、供应方、世界建立 | 字段标签在输入框上方，字段间距 16，删除放最后一节并二次确认 |
| 四级 | 编辑器里的 sheet、确认弹窗 | 只放一个决定，长文编辑不用 sheet，未保存改动关闭前确认 |

共用件在 `Core/Design/AppComponents.swift`。二级和三级页优先用 `Form`、`List` 加 `AppSectionHeader`、`AppSettingsRow`、`AppTextField`、`AppTextArea`、`AppSecureField`、`AppTextEditor`、`PrimaryActionButton`、`DestructiveActionRow`、`StatusPill`、`AppStatusLine`。不得手写分隔线区块或卡片套卡片，也不得将 `TextEditor` 放入外层 `ScrollView`。

保存语义：

- 自动保存页只显示「完成」，不显示自动保存角标。
- 显式保存页用「取消」丢弃、「保存」提交，保存按钮不兼职切换当前项。
- 只有「保存」没有「取消」的编辑页，左滑返回时自动保存非空改动；带草稿的 sheet 关闭前确认放弃，不能静默丢输入。
- 清除 Key、清零用量、恢复默认、删除分组、删除词条、删除书稿都要确认，可撤销的操作应提供撤销。
- 滑块只在松手时落盘，不逐 tick 写整份 `settings.json`。
- 发送或续写后键盘收起，流式文本进对话区；插入和追加都有确认与撤销。

阅读页正文优先，常驻控件不超过 4 个，其余进菜单。

## 6. 信息架构

设置分三级：

| 级 | 放什么 | 硬约束 |
|---|---|---|
| 一级 | 分类列表：连接与模型、写作、数据、外观与交互、关于 | 一屏看完，不超过 6 行 |
| 二级 | 该分类的功能页 | 一页不超过 4 个区块 |
| 三级 | 编辑器或弹层：供应方、技能、语料库、世界建立、存档 | 只做一件事 |

缺 Key 这类全局提醒只在一级留一条可点入口，不铺成卡片。

书架在 sheet 里分三段：继续写作、全部书稿、回收站和设置入口。不铺大封面网格，书脊、书名和最近编辑时间就是索引，书脊占位色只用于封面。回收站是 push 出来的独立页，行内只留「恢复」，彻底删除走滑动加确认。

世界页分概览、世界书、人物卡、事件卡、模板与规则。概览只放刷新入口和资料计数，没有单段「世界设定」编辑器，旧设定文本迁移成世界书词条。资料计数点击行切换分栏，不写实现说明。

## 7. 体验依据

方法参考内置的 [ios-taste 技能](skills/ios-taste/SKILL.md)（vendored，MIT，见 [NOTICE](skills/ios-taste/NOTICE.md)）；改界面以本页规则为准。

### 7.1 用户与场景

用户是写长篇中文小说的作者，常在手机上用整块时间写作，一本书可能超过 50 万字。

打开应用时，用户通常希望接着上次的段落写作，或者先让码字机写一段再改。环境一般安静，通常单手持机，另一只手用于选字或粘贴。

用户需在 10 秒内完成三项操作：确认正文当前进度，输入或生成下一段，插入正文并确认位置。

界面的情绪目标是 calm、focused、可信，但不是纯白毛坯：层次来自系统材质、轻投影、字号、留白和更精细的间距，装饰要服务内容，不能喧宾夺主。正文始终是第一层，导航和操作退后。

### 7.2 半秒测试

| 页面 | 用户先看到什么，不看字 |
|---|---|
| 创作 | 一整列对话气泡，底部一条输入条。正文入口在导航栏，不与对话争夺空间 |
| 阅读 | 一页小说，正文和页脚进度，目录、搜索、设置在导航栏 |
| 世界 | 概览里的刷新入口和资料计数，世界书、人物、事件、规则各一栏 |
| 设置 | 原生分组列表，分类入口点击后展开 |

创作页优先显示对话，因为该页的主要操作是明确本轮写作要求。正文是对话的上下文，点击正文进入全屏页阅读或编辑。

## 8. 文案规则

### 8.1 可以写

| 类型 | 例子 |
|---|---|
| 标题 | 页面标题、区块名、字段名、按钮名 |
| 数值、计数、状态 | `2 张`、`4 分钟前`、`未填写`、`当前`、`已缓存` |
| 服务端或错误原文 | 测试连接失败时服务端返回的正文，导入失败的具体键名 |
| 极短占位 | 输入框 placeholder，例如「书名」「人物本名」 |
| 原版有证据的空态句 | 见下表 |
| 法定署名 | `Power by Fr33`、移植声明、版本行 |

### 8.2 不写

- 区块副标题和 footer 里的解释，比如「写作、整理和翻译默认都走……」。
- 行副标题，比如「全局预设、技能、本书补充指令」。
- 操作说明，比如「点行尾的 ⋯ 可以……」「左滑可……」。
- 实现或行为解释，比如「Key 只存本机钥匙串」「模型留空时使用……」「主写作固定 0.2」。
- `InlineHint`、`settingsNote` 和自动保存小字，比如 `AutosaveBadge`。
- 确认弹窗里的解释性 message。只留标题和动作按钮。
- 空态里自己编的引导句。只留原版有证据的句子或标题。

### 8.3 原版有证据、可以保留

| 页面 | 原文 | 证据 |
|---|---|---|
| 世界书空态 | 「当前项目尚无世界书」和「添加设定后，只保存在这本书中。」 | `M1/C0722m.java:366` |
| 宇宙头部 | 「全局预设、共享世界书与 Skill」 | `M1/C0738o.java:312-313` |
| 世界页头部 | 「世界」和「这本书的设定与人物」 | `M1/C0738o.java:167-168` |
| 书架标题 | 「本机书架」 | `01-architecture.md:224` |
| 回收站状态 | 「项目已在回收站」「项目已恢复到书架」「项目已从书架隐藏」 | `dex-chinese.txt:1940,1941,143` |

字符串表或规格中查不到出处的文案，视为自拟文案并删除。

## 9. 评审清单

- [ ] 底色是白或黑，不是分组灰
- [ ] 去掉填充色后层级仍成立
- [ ] 没有小于 `.caption` 的字
- [ ] 没有给文字写死的 `frame`（图标、封面、控件的固定尺寸不算）
- [ ] 可点热区至少 44×44pt
- [ ] 没有装饰性渐变或光晕；渐变只允许出现在进度、图表等数据表达里
- [ ] 卡片没有叠卡片，投影没有糊在深色模式
- [ ] 异步加载页先显示加载态，不先闪空态
- [ ] 文件面板后的确认不是同层 alert
- [ ] 显式保存页返回不静默丢输入
- [ ] 标签和值两端对齐
- [ ] 一屏最多一个 `.borderedProminent`
- [ ] 没有解释实现的文案
- [ ] 状态行单行，图标在文字前，动作在行尾
- [ ] 键盘不遮底部输入条
- [ ] 深色模式投影不糊
- [ ] 最大动态字体不裁字
- [ ] 阅读页常驻控件不超过 4 个
